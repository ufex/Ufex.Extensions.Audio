# Ufex.Extensions.Audio

A collection of [Ufex](https://github.com/ufex) C# plugin projects for audio file formats.

## Plugins

| Project | Format(s) | Description |
|---------|-----------|-------------|
| **FLAC** | Free Lossless Audio Codec | Parses RFC 9639 metadata, tags, cuesheets, pictures, seek points, and audio frame headers. |
| **MIDI** | Standard MIDI File | Parses the MIDI header, track chunks, channel messages, system exclusive events, and meta events. |
